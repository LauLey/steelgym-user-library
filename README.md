# Steel Gym User Management

Aplicación web para la gestión básica de usuarios y membresías de Steel Gym.

Este proyecto surge como una iniciativa para explorar la digitalización de procesos administrativos y mejorar la organización de la información relacionada con los usuarios del gimnasio.

Actualmente se encuentra en desarrollo y utiliza datos ficticios como parte de su etapa de prototipado.

## Objetivo

Crear una herramienta sencilla que permita centralizar información básica de los usuarios y facilitar la consulta y gestión de su estado de membresía.

La aplicación permitirá:

* Registrar nuevos usuarios.
* Consultar información básica de los usuarios.
* Identificar cada registro mediante un identificador único.
* Consultar el tipo de membresía.
* Cambiar el estado de una membresía entre activo e inactivo.
* Eliminar registros cuando sea necesario.

## Información del usuario

Cada registro contempla inicialmente:

* Nombre
* Fecha de nacimiento
* Teléfono
* Tipo de membresía
* Estado de la membresía
* Identificador único
